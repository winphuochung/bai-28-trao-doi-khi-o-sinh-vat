# Web/app học tập — Khoa học tự nhiên 7, Bài 28

**Bài 28: Trao đổi khí ở sinh vật**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.
Chương VII: Trao đổi chất và chuyển hóa năng lượng ở sinh vật · Tuần 23 · Tiết 90–92.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng gồm:
1. Khí khổng đóng – mở ở lá (hình SVG thay đổi theo thanh trượt ánh sáng và nước: hai tế bào hình hạt đậu mở/khép, hạt khí CO₂ đi vào lá, O₂ và hơi nước đi ra).
2. Hít vào – Thở ra ở người (hình SVG đường dẫn khí: khoang mũi → hầu → khí quản → phế quản → phổi phồng/xẹp, cơ hoành hạ/nâng).

Khóa đáp án trắc nghiệm: 1A 2C 3C 4B 5B 6B 7C 8D 9A 10B (ACCBBBCDAB).

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai28.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — code Apps Script Web App ghi điểm về Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền JPEG 1376×768 (đăng nhập, nền chính, hero) + logo cá nhân của Thầy (PNG 500×500 trong suốt).
